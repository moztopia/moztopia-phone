# Security reports

Do not put telephone-number values, customer datasets, secrets or exploit details in public issues. GitHub private vulnerability reporting is currently not enabled for this repository. Request a private reporting channel from a repository maintainer without including sensitive details; maintainers decide the appropriate reporting mechanism.

This package performs local metadata-based processing. Host applications remain responsible for authorization, storage, logs, request limits and deployment configuration. Extraction's input bound is not a strict CPU-time guarantee. Report issues with a synthetic reproduction, dependency versions and PHP version.
